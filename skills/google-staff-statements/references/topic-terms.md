# Topic → search terms

These people write in everyday language; instead of the terms used in official documentation they use
abbreviations, slang and jokes. When searching a topic, try the terms below together or with `OR`. The topic name
may not appear in the person's reply: if there are few results, add `--in-question`.

| Topic | Terms to try |
|---|---|
| Canonical | `canonical OR rel=canonical`, `"duplicate content"`, `"chosen canonical"`, `"user-declared"` |
| Noindex / robots | `noindex`, `robots.txt`, `disallow`, `"blocked by robots"`, `x-robots-tag` |
| Crawl budget | `"crawl budget"`, `"crawl rate"`, `"crawl demand"`, `googlebot crawling`, `"server capacity"` |
| Indexing problems | `"crawled currently not indexed"`, `"discovered currently not indexed"`, `indexing`, `"not indexed"` |
| Redirects | `redirect`, `301 OR 302`, `"site move"`, `migration`, `"change of address"` |
| Hreflang / international | `hreflang`, `x-default`, `geotargeting`, `ccTLD`, `"country targeting"` |
| Sitemap | `sitemap`, `lastmod`, `"sitemap index"` |
| JavaScript SEO | `javascript rendering`, `"client-side"`, `hydration`, `"dynamic rendering"`, `SSR` |
| Links | `backlinks`, `"link building"`, `nofollow OR ugc OR sponsored`, `"toxic links"`, `disavow`, `"link spam"` |
| Core updates / ranking | `"core update"`, `"ranking systems"`, `"helpful content"`, `HCU`, `recovery`, `"site-wide"` |
| E-E-A-T / authors | `E-E-A-T OR EEAT OR EAT`, `"author bio"`, `expertise`, `"quality raters"` |
| AI content | `"AI content" OR "AI-generated"`, `"scaled content"`, `LLM`, `ChatGPT`, `"AI Overviews" OR "AI Mode"` |
| Site reputation / parasite SEO | `"site reputation abuse"`, `"parasite SEO"`, `"third-party content"` |
| Subdomain / subfolder | `subdomain subfolder`, `subdirectory`, `"separate site"` |
| Core Web Vitals | `"core web vitals" OR CWV`, `LCP OR INP OR CLS`, `"page experience"`, `pagespeed` |
| Structured data | `"structured data"`, `schema`, `"rich results"`, `json-ld` |
| Search Console | `"search console"`, `GSC`, `"URL inspection"`, `impressions`, `"performance report"` |
| Content length / word count | `"word count"`, `"content length"`, `"thin content"` |
| Domain age / authority | `"domain authority"`, `DA`, `"domain age"`, `sandbox` |
| Click data / Navboost | `clicks ranking`, `CTR`, `"user signals"`, `navboost`, `"dwell time"` |
| Spam | `spam`, `"manual action"`, `penalty`, `"spam update"`, `cloaking`, `"doorway"` |

Notes:

- "Penalty" is a word most of these people avoid; also search with `"manual action"` and `demotion`.
- Mueller often says "it depends" and "there's no fixed number"; if a numeric threshold is being asked about,
  verify the exact phrase with `find`.
- For leak topics (Navboost, siteAuthority) this archive only shows what employees said; for the leaked fields use
  the google-leak skill.
